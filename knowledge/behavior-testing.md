# 前端行为测试公共规则

版本：3。适用于 Vue 前端的非浏览器业务流程测试；具体业务预期由项目需求、CONTEXT.md 和 ADR 决定。

## 会话报告与项目说明

工具包接入、升级、适配过程和验收流水仅在用户会话中输出，不写入项目测试指南、独立报告、变更日志或其他文档。会话中报告实际命令与结果、规则来源与版本、验证范围、失败诊断和剩余问题。项目测试说明只维护持续有效的运行命令、测试入口、宿主用法、隔离清理约束和能力限制；机器使用的配置、来源锁文件与规则摘要照常维护。新的会话通过现有配置、契约测试及实际执行确认环境状态，不依赖历史验收文档。

## 初始化与验收分层

分别在用户会话中报告基础工具链、应用宿主和业务流程的验证结果。通用 Vue/DOM/HTTP 冒烟只证明基础工具链；默认项目初始化还应验证应用宿主。没有具体业务需求时不编造业务场景，业务覆盖可以为空。

先检查项目依赖、启动入口及已有测试支持，按实际使用的能力构建或复用宿主。状态库、路由、组件库、微前端宿主、消息和设备接口均为条件适配项；未使用的能力记录为不适用，不为满足模板安装或模拟它们。没有这些额外依赖时，宿主可以只是复用现有渲染与清理入口。

宿主验收使用最终项目测试配置加载代表性的真实业务模块，以及项目实际使用的组件库。若模块导入依赖状态容器、应用全局或消息接口，先完成对应初始化。模块顶层捕获 store 时，初始化顺序及重置策略须保持引用一致。依赖 API 以项目安装版本为准。

只在实际存在的宿主和设备等外部边界提供最窄替身；未配置的设备调用明确失败。通过重复场景验证项目实际持有的状态、消息记录和设备覆盖的隔离，以及挂载、订阅和全局修改等实际副作用的清理。保留可复用宿主与有长期价值的契约测试，宿主契约不计为业务覆盖。

基础工具链通过但宿主未验证时，明确交付“基础工具链通过，应用宿主待验证”；列出已验证的模块和外部能力边界，不能推广成所有页面可用。静态配置检查、空套件或跳过用例均不能作为运行验收。

## 入口与断言

从真实页面 DOM 操作或已约定的业务公共接口触发功能。检查用户可观察结果和外部协议。页面测试 helper 只封装操作与查询，不重写业务判定，不调用页面私有方法。独立预期来自需求或人工可核算样例，不调用被测算法生成预期。

## 真实实现与外部适配

保留真实业务组件、项目使用的状态管理逻辑、hooks、service/adapter 和 HTTP 拦截器。HTTP 在网络边界提供精确响应；设备、宿主和打印在真实外部接口提供替身。需要替换模拟 DOM 不支持的能力时，记录能力缺口和最窄替换位置。

## 场景生命周期

每条测试创建独立状态，清理挂载、弹窗、事件、存储、定时器和场景数据。未声明网络请求使测试失败。异步操作等待可观察结果；固定延时不能充当完成条件。

## 验证与旧测试迁移

开发逐个行为推进。缺陷修复先复现；既有功能补测用可逆故障确认断言能发现对应错误。保留测试类型检查和相关回归证据。旧测试按业务规则映射替换，复杂计算和历史缺陷覆盖可以保留；不以删除数量或覆盖率数字作为完成指标。

## 知识与执行

开发阶段记录规则来源和内容版本；已生成的测试在离线 Node/CI 中可执行。知识检索结果是参考材料，历史记忆不能自动变成正式规则。明确报告知识不可用、缺失或版本不一致；禁止以“没有规则”掩盖连接失败。OpenViking 插件的开启遵循用户授权，不由初始化工具修改。
