# Vue 3 行为测试环境基线 v1

本基线约束测试环境、HTTP 隔离和项目适配接口。具体业务规则与页面实现由使用方仓库维护；工具包执行与验收结果按公共规则仅在用户会话中报告。

## 运行条件

使用已有 Vue 3 应用，检查 Node、包管理器及依赖 engines。默认测试依赖版本以 `lib/bootstrap.mjs` 为准；已有兼容版本予以保留，以实际安装、环境冒烟和类型检查结果判断兼容性。解析版本由项目锁文件记录。

## 测试接口

1. 从真实 DOM 驱动页面，保留项目实际使用的 providers、状态管理、router、业务子组件与 HTTP 客户端；未使用的能力无需补装。
2. MSW 在网络边界提供精确场景响应。未声明请求须记录并让用例失败，即使业务代码捕获了网络异常也不能掩盖它。每例重置 handlers，套件结束关闭 server。
3. 项目自行实现 render/cleanup，复用生产初始化；状态、弹窗、事件、存储和定时器需要独立生命周期。必要时为生产单例增加最小释放接口并验证回归。
4. 复用已有 Vue/TSX、组件解析、别名及样式配置。可以关闭模拟 DOM 不需要的资源下载，保留业务 HTTP 请求链路。
5. 宿主、设备与 HTTP 是外部适配边界。组件库导入不可用设备 SDK 时，可在该接口提供调用即失败的替身。
6. profile 映射项目真实脚本、flowConfig、flowDirectory 和测试说明；已有目录及脚本名称可以保留。
7. 测试文件有独立类型检查；编译、环境冒烟和真实业务流程分别验收。
8. 临时环境用例与调试代码在验证成功后清理，公共支持与真实回归保留。清理后修复引用并重跑受影响的检查，记录保留验证代码的用途。

## 接入流程

先预览 CLI init，检查依赖与文件计划；已有环境按 [项目适配说明](project-adaptation.md) 增量接入。项目内 skill 提供初始化和日常行为测试工作流，两个 skill 及其共用工具快照一起纳入 Git。

默认规则来自 `knowledge/catalog.json` 及其正文快照，在 profile 固定摘要。已有其他知识来源时遵循其配置与连接授权，示例见 [知识提供方](knowledge-providers.md)。初始化不会启用插件，测试执行独立于在线知识服务和模型。

业务流程从项目需求中选择，先验证一个完整结果，再补相关失败分支。按 [接入验收清单](project-acceptance.md) 在用户会话中报告命令和证据；旧测试只在对应业务规则已被验证后替换。
