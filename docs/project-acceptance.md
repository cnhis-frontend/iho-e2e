# 项目接入验收清单

验收结果保存在使用方仓库的测试说明中。工具包提供通用流程与验证方法，业务预期由该项目的需求、spec、CONTEXT.md 或 ADR 提供。

## 环境就绪

- 测试依赖已实际安装，运行时与包管理器符合项目约定。
- Vue 组件编译、DOM 用户操作、MSW 请求响应与可见结果断言形成可执行的环境冒烟。
- 测试源码和支持文件进入类型检查，真实检查命令已通过。
- profile 映射实际配置、目录、脚本和项目测试说明；重复初始化保留定制。
- 知识来源、版本或摘要有记录，规则读取与静态 doctor 验证通过。
- 两个项目内 skill 及工具快照可纳入 Git，脚本使用项目内资源。

环境冒烟不计为业务覆盖。只要求搭建环境时，报告“环境就绪”，并明确尚未接入真实业务流程。

## 业务流程接入

- 根据独立需求选择流程，保留真实页面、状态及 service/adapter 链路。
- 列出外部替身及其边界，覆盖相关成功与失败、取消或权限分支。
- 用真实 DOM 操作或约定的公共接口触发功能，断言用户可观察结果和外部协议。
- 流程套件非空、没有跳过用例，测试类型检查与 `doctor --run` 通过。
- 通过缺陷复现或可逆故障验证断言能够发现错误。
- 旧测试的替换有业务规则映射；无关历史失败单独记录。

## 交付记录

记录真实命令及结果、已覆盖行为、使用的外部替身、规则来源，以及未验证的能力。避免把编译通过、环境冒烟通过或某个项目的接入结果推广为其他项目已完成。
