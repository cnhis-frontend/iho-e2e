# 项目接入验收清单

按公共规则“会话报告与项目说明”，工具包接入、升级、适配过程和验收流水仅在用户会话中输出，不落实为文档。项目测试说明只保留持续有效的使用说明。工具包提供通用流程与验证方法，业务预期由该项目的需求、spec、CONTEXT.md 或 ADR 提供。

## 基础工具链

- 测试依赖已实际安装，运行时与包管理器符合项目约定。
- Vue 组件编译、DOM 用户操作、MSW 请求响应与可见结果断言形成可执行的环境冒烟。
- 测试源码和支持文件进入类型检查，真实检查命令已通过。
- profile 映射实际配置、目录、脚本和项目测试说明；重复初始化保留定制。
- 知识来源、版本或摘要有记录，规则读取与静态 doctor 验证通过。
- 两个项目内 skill 及工具快照可纳入 Git，脚本使用项目内资源。
- 环境验证成功后移除临时用例、示例及调试代码，保留公共支持与有实际回归价值的用例；失效引用已修正，清理后的正式检查通过。

通用冒烟仅证明基础工具链。验收分层的公共要求见 catalog 中的 `iho.behavior-testing`；默认初始化继续完成应用宿主，业务覆盖可以为空。

## 应用宿主

- 按 `project-adaptation.md` 的 Application host acceptance，在最终项目测试配置下验证代表性真实模块加载及宿主生命周期。
- 项目保留可复用宿主与独立契约 suite，在会话中报告实际模块、外部替身和验证边界。
- profile 的 `scripts.host` 映射真实命令；测试类型检查包含宿主源码和契约 suite。
- `doctor --host` 通过，套件非空且无跳过；清理临时探针后仍能运行。

基础工具链和宿主均通过后可以交付初始化。宿主待验证时单独说明，不能合并报告“环境就绪”。宿主契约数量不计入业务覆盖。

## 业务流程接入

- 根据独立需求选择流程，保留真实页面、状态及 service/adapter 链路。
- 列出外部替身及其边界，覆盖相关成功与失败、取消或权限分支。
- 用真实 DOM 操作或约定的公共接口触发功能，断言用户可观察结果和外部协议。
- 流程套件非空、没有跳过用例，测试类型检查与 `doctor --run` 通过。
- 通过缺陷复现或可逆故障验证断言能够发现错误。
- 旧测试的替换有业务规则映射；无关历史失败单独记录。

## 会话交付

仅在用户会话中报告真实命令及结果、已覆盖行为、使用的外部替身、规则来源，以及未验证的能力。避免把编译通过、环境冒烟通过或某个项目的接入结果推广为其他项目已完成。
